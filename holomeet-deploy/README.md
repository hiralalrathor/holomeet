# HoloMeet (full stack)
    npm install
    npm start        # http://localhost:3000
Open the same `#room` link on two devices. Optional env vars: `PORT`, `REDIS_URL` (room board with 6h TTL), `TURN_URL` / `TURN_USER` / `TURN_PASS` (firewall traversal).
Deploy on Render, Railway or any Node host. Mic, camera and screen share need HTTPS (localhost is fine).
