# HoloMeet
Pages: `/` sign in / sign up / guest -> `home.html` (new meeting, join by code) -> `meet.html` (video call) or `holo.html` (3D room).
    npm install && npm start   # http://localhost:3000
Env: `SECRET` (token signing, auto-generated by render.yaml), `REDIS_URL` (keeps accounts and board data), `TURN_URL` `TURN_USER` `TURN_PASS`.
Without REDIS_URL accounts are saved to data/users.json, which Render's free plan erases on every redeploy.
Meeting extras: host controls (mute all, remove), emoji reactions, live captions (browser speech recognition), active-speaker highlight, pin a tile, local recording, invite links, recent meetings.
